# 贴吧清爽净化助手

一个让百度贴吧页面更清爽的浏览器用户脚本（Tampermonkey / Violentmonkey 等）：去除广告与推广干扰、精简页面模块、优化阅读体验、还原中转外链，全部功能可在设置面板中独立开关。

## 功能一览

### 净化

| 开关 | 作用 |
|---|---|
| 去除广告模块 | 隐藏帖子列表与楼层中插入的推广卡片、信息流广告等广告节点 |
| 隐藏活动横幅 | 隐藏顶部活动推广条、信息推荐轮播与帖子页品牌横幅 |
| 隐藏悬浮器件 | 隐藏页面两侧对联广告、侧边吸附浮层与底部关注提示 |
| 隐藏会员推广 | 隐藏会员购买引导、楼层成就徽章与签名推广提示 |

### 精简

| 开关 | 作用 |
|---|---|
| 隐藏右侧栏并居中 | 隐藏帖子页与主页右侧信息栏，主栏内容居中显示 |
| 隐藏签名档 | 回复下方的个人签名图与分割线不再显示 |
| 隐藏楼层杂物 | 隐藏分享按钮、送礼按钮、发帖成功推广等干扰元素 |
| 会员彩名恢复默认 | 列表与帖子页的会员彩色昵称恢复为常规文字颜色 |

### 阅读

| 开关 | 作用 |
|---|---|
| 帖子页宽屏 | 放宽帖子页内容列宽，正文图片随列宽自适应 |
| 图片原图显示 | 帖子内图片自动加载原始尺寸，替代压缩缩略图 |
| 高亮楼主楼层 | 楼主发出的楼层以淡蓝底色标出，长帖快速定位 |

### 链接

| 开关 | 作用 |
|---|---|
| 中转链接直链化 | 帖子里的外链跳转中转页直接还原为目标网址，点击直达 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等脚本管理器）。
2. 新建脚本，粘贴本目录 `tieba-enhance.user.js` 的全部内容并保存。
3. 打开任意百度贴吧页面即可生效。

## 使用

- 所有功能默认开箱即用，无需任何操作。
- 点击脚本管理器图标中的「打开设置面板」即可开关各项功能、按需取舍。
- 面板内切换开关**立即生效，无需刷新页面**。
- 按 `Esc` 或点击遮罩可关闭面板。

## 行为说明

- 广告隐藏分两层：常规广告位由样式规则直接隐藏；混在帖子列表/楼层中间的插入广告（无帖子 ID 特征）由脚本识别后隐藏，置顶帖与公告不会被误伤。
- 图片原图化只处理帖子正文图片，列表缩略图不受影响。
- 中转链接还原只处理明确的跳转域名，百度站内链接与无法解析的链接保持原样。
- 未登录浏览不受影响；脚本不处理登录、不触碰账号与风控逻辑。

## 限制

- 贴吧页面结构改版时，个别隐藏规则可能失效；脚本功能均为独立开关，出现误伤可单独关闭对应开关排查。
- 「隐藏右侧栏并居中」在窗口极窄时效果有限，属布局本身限制。

## 隐私

- 不发起任何网络请求，不收集任何数据。
- 开关状态仅保存在本地脚本管理器的存储中。
