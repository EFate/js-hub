# 网盘直链下载助手（netdisk-hub）

**是什么**：一个油猴脚本（Tampermonkey / Violentmonkey / ScriptCat），装上之后在网盘页面里勾选文件，点工具栏上的「下载助手」，直链就会自动出现 —— 一键交给 **Aria2 / Motrix / IDM / 浏览器** 高速下载，绕开客户端限速与浏览器单线程的慢。

**三步用法**：勾选文件 → 点「下载助手」→ 点「Aria2」推送。文件夹取不出直链，请点进文件夹后勾选其中的文件。

## 直链与账号的关系

**一句话：直链就是「你当前登录的账号」在页面上点「下载」会得到的那条地址。** 脚本只做「提取与转交」，不改变账号权益 —— 直链由网盘服务端按账号身份签发，下载速度也由服务端按账号判定。

### 会员 / 普通账号分别拿到什么？

| 账号 | 换到的直链 | 下载速度 |
|---|---|---|
| **会员（VIP / SVIP）** | 与普通账号**同一条接口**换出，地址格式相同 | **会员速度**（服务端按账号放行） |
| **普通账号** | 同上，接口与格式完全一致 | 普通速度（各网盘对非会员限速） |
| **未登录（游客）** | 部分网盘可换（夸克 / UC），但有**单文件大小上限**，超限直接拒绝 | 最低档限速 |

> 脚本**不能**把普通账号变出会员速度 —— 那是服务端按 Cookie 里的账号身份判定的，任何直链工具都一样。脚本能保证的是：你账号**本来就有**的权益，通过 Aria2 / Motrix / IDM 多线程跑满，而不是被浏览器单线程浪费掉。

### 各网盘获取条件明细

| 网盘 | 需要登录 | 页面 / 提取码要求 | 直链附加校验 | 当前状态 |
|---|---|---|---|---|
| **百度** | ✅ 必须 | 分享页需已通过提取码验证；网盘内页**首次换链自动完成百度授权**（开放平台令牌，缓存复用） | 下载需 UA `pan.baidu.com` + Referer + **Cookie**；浏览器直接访问超 50MB 的直链会 403 | 分享页 + 内页自动换链 ✅ |
| **夸克 / UC** | 建议登录 | 分享页需过提取码（stoken） | 下载需**客户端 UA** + 页面 Referer + Cookie | 自动换链 ✅；未登录报「超出游客大小上限」 |
| **阿里云盘** | ✅ 必须 | 换链接口需 OAuth access_token（暂未接入） | 直链需 Referer | 截获兜底 |
| **123 云盘** | ✅ 必须 | 分享页需过提取码 | 接口校验登录态 | 截获兜底 |
| **移动云盘** | ✅ 必须 | **官方限制：只能页面直接下载**，无法接口换链 | — | 截获兜底（最合适的路径） |
| **天翼云盘** | ✅ 必须 | 换链需 AccessToken + 签名（暂未接入） | — | 截获兜底 |
| **迅雷云盘** | ✅ 必须（未登录服务端直接拒绝） | 分享页需页面内部 token | 直链 CDN 可能是会员专属节点 | 截获兜底 |

### 直链的时效与使用要点

- **直链带签名，有时效**（几分钟到几小时不等，各网盘不同）—— 换到后尽快推送，过期了重新获取一次即可。
- **请求头必须随行**：直链不是裸地址，网盘会校验 UA / Referer / Cookie，脚本已自动随直链保存并带入 Aria2 推送，你不需要手动配置。
- **错误提示按账号状态直达**：未登录 → 提示登录；游客超限 → 提示登录后获取；分享页过期 → 提示刷新页面。

## 设计理念

**两种识别方式，一主一兜底。**

**主：读页面框架状态。** 网盘是 SPA，「有哪些文件」「勾选了哪些」都存放在 **React / Vue 的内部状态**里，而不在 DOM 上 —— 这正是扫 DOM 必然一无所获的原因。脚本从文件列表的容器反查框架实例，直接读出勾选的文件（`props.list` + `props.selectedRowKeys`、`__vue__.allFileList` 等），再调网盘接口换直链。**勾选文件后打开面板，直链自动就位。**

**兜底：网络层捕获。** 对尚未实现换链的网盘，脚本在文档解析前 hook `XMLHttpRequest` 与 `fetch`，您在网盘里点一次「下载」，直链就会被截下来，落进「可用直链」列表。

**入口融入页面，不做悬浮器件。** 脚本把「下载助手」按钮注入到网盘页面**既有的工具栏容器**内，与宿主原生按钮并排；不产生任何脱离文档流的悬浮球、胶囊或侧边吸附按钮，也不占用快捷键。

**菜单兜底。** 宿主改版可能导致注入点失效，因此始终同时注册脚本管理器菜单命令，保证任何情况下都能进入面板。

**开箱即用。** Aria2 配置默认适配常见的本机部署（`http://localhost:6800/jsonrpc`），装完即可用，改配置只需填 4 个字段。

**零第三方依赖。** 全部功能自实现，不引入 jQuery / SweetAlert2 / 加密库等外部资源，没有 `@require` 外链，不存在供应链风险与加载失败问题。

**可插拔网盘适配。** 网盘支持做成配置表，新增一个网盘只需要在 `providers` 数组里追加一项。

## 功能

### 勾选即识别（主通道）

| 步骤 | 说明 |
|---|---|
| 读页面框架状态 | 从文件列表容器反查 React fiber / Vue 实例，读出勾选的文件（fid / 文件名 / 大小 / stoken） |
| 分流 | **文件夹换不出直链**，单独标出并从请求里剔除；剩下的文件才进入换链 |
| 调网盘接口换链 | 带上网盘要求的请求头（含页面 Referer 与 Cookie），调其 `file/download` 一类接口换取直链（分批 + 节流，避免触发风控） |
| 入库候选池 | 直链进入「可用直链」，可逐条或批量推送 Aria2；**取链时带下来的请求头会一并保存并随推送发出** |

各网盘的框架与字段都不同，已按网盘分别实现。**文件夹判据也已按各网盘的真实字段收敛**（夸克/UC 用 `file`、百度用 `isdir`、阿里用 `isDir`、123 用 `IsFolder`）—— 早期版本统一按 `dir` 判断，在夸克上恒为 false，于是文件夹被当成文件送进换链接口，结果一条直链也取不回来。

> **为什么文件夹取不到直链？** 网盘的 `file/download` 接口只接受文件 ID，文件夹需要先遍历其内容再逐个取链。因此勾选含文件夹时，脚本会明确提示「请进入文件夹后勾选其中的文件」，而不是发一次注定无结果的请求。

### 直链捕获（兜底通道）

在文档解析前 hook `XMLHttpRequest` 与 `fetch`，通过**三条渠道**截获：

| 渠道 | 说明 | 可靠性 |
|---|---|---|
| 请求 URL | 只认高置信特征（`dlink=`、`dl.` 域名前缀、`/download?`）；接口路径与静态资源一律排除 | 中 |
| 接口响应体 | 递归提取 `dlink` / `download_url` / `download_link` 等键承载的地址，并带上文件名与大小 | 高 |
| 响应头 | 服务端声明 `Content-Disposition: attachment` 或 `application/octet-stream` 时，该请求 URL 即直链 | 高 |

**入库按「文件名」合并，而不是按 URL** —— 网盘直链每次都带新签名，按 URL 去重挡不住「重新获取」产生的重复。同名即同一文件，覆盖为最新一条（签名与请求头随之更新），点多少次都不会堆叠。池上限 60 条；面板打开期间每 1.5 秒刷新一次。

> **为什么只认高置信特征？** 早期版本允许「对象存储 / CDN 域名 + 带查询串」入池，结果把大量普通接口请求也收了进来 —— 候选列表里会刷满 `usercode`、`report` 这类噪声。宁可少收，也不要污染列表。

### 下载出口

面板里**每条直链固定三个出口**，保持一眼可辨：

| 出口 | 说明 |
|---|---|
| 推送 Aria2 | JSON-RPC `aria2.addUri`，自动携带文件名、保存目录与业务请求头（含换链时带下来的 Referer / Cookie） |
| 下载 | 用隐藏 iframe 触发浏览器原生下载，不被弹窗拦截 |
| 复制 | 复制原始直链，可粘到任意下载工具 |

另有**一个可选出口**，默认关闭，在「设置 → 偏好设置」里打开后会出现在每条直链上：

| 可选出口 | 说明 |
|---|---|
| IDM | 通过 IDM 本地捕获端口推送（需本机已安装较新版本 IDM） |

> 曾有「增强下载」（浏览器内分片并发再合并）—— 评估后移除：它要求整个文件先进内存，不落盘、不能暂停续传，数 GB 文件会撑爆标签页，不符合浏览器下载设计。要并发请交给 Aria2 / Motrix / IDM。

配套的 Aria2 工具：

| 工具 | 说明 |
|---|---|
| 全部推送 Aria2 | 一键把当前所有直链排进队列，单条失败不阻断其余 |
| 复制全部 | 全部直链按行拼接（CRLF），一次粘贴到任意下载工具 |
| 复制命令行 | 每行一条 `aria2c` 命令，未启用 RPC 时也能用，便于脚本化处理 |
| 测试连接 | `aria2.getVersion` 探测，成功后在界面回显版本号 |

### 其它

- **空列表只给一句话**：没有直链时只显示「现在该做什么」（去勾选文件 / 去点一次下载 / 进入文件夹），不展示任何统计。
- **任务历史**：最近 20 条推送记录持久保存。
- **容错输入**：服务器地址支持 `localhost:6800`、`http://localhost:6800/`、`127.0.0.1:7000` 等写法，自动补协议、拆端口。
- **密钥自适应**：未设置 `rpc-secret` 时不发送 secret 参数，避免部分版本报错。

## 安装

1. 安装 Tampermonkey / Violentmonkey / ScriptCat 等脚本管理器。

3. 打开任意受支持的网盘页面。

## 使用

### 入口（两条）

1. **网盘工具栏按钮**（首选）—— 打开受支持的网盘页面后，脚本会等待宿主工具栏渲染完成，把「下载助手」按钮注入进去，与宿主原生按钮并排。点击即可打开面板。
2. **脚本管理器菜单**（兜底）—— 点脚本管理器图标 → 菜单中的「打开下载助手」。注入点因宿主改版而失效时使用这条。

第一次使用时脚本会弹一次 Toast 提示入口位置（可在「设置 → 首次提示」关闭）。

### 典型用法

1. 打开网盘页面，在文件列表里**勾选**要下载的文件。
2. 点工具栏上的「下载助手」按钮 —— 面板打开，**直链自动换取**，直接出现在「可用直链」里。
3. 点该条右侧的 **Aria2** 即完成推送；也可以「下载」交给浏览器，或「复制」链接。

> 若所用网盘尚未实现换链（见上表），改用在网盘里点一次「下载」，由脚本自动截获。
>
> 想重新取一次，点底部的「重新获取直链」即可；同一批勾选不会重复请求。

### 面板

**下载页只有一张卡：可用直链。** 没有直链时，卡里只显示一句话告诉你该做什么 —— 不展示「勾选了几项、几个文件几个文件夹」这类统计。列表里有内容时才出现批量按钮，底部是「重新获取直链」一个次要入口（仅在当前网盘支持自动换链时出现）。

**设置页两张卡**：Aria2 服务器（服务器地址 / 密钥 / 保存目录 / 接口路径 + 测试连接 / 保存）、偏好设置（IDM 出口 / 首次提示）。偏好设置的每一项都是「名称 + 一句短说明 + 开关」，说明直接写在名称旁边，不放冗长文案。

> 服务器地址把「主机 + 端口」合并成一行填写，例如 `http://localhost:6800`；保存时自动拆回内部字段。

## 网盘识别细节

> 上表是总览；这里是各网盘的技术细节（页面判据、框架取数字段），供扩展与排障参考。

**关于夸克 / UC 的换链细节**（这几处缺一不可，也是踩过坑的地方）：

- **夸克与 UC 是两家接口。** 采集逻辑相同，但换链地址与客户端 UA 不同 —— 夸克走 `drive-pc.quark.cn/...pr=ucpro` + `quark-cloud-drive` UA，UC 走 `pc-api.uc.cn/...pr=UCBrowser` + `uc-cloud-drive` UA。脚本按当前域名自动区分，混用必然失败。
- 分享页的分享 ID 依次从 `factStat.ut.baseParams.pwd_id`、`factStat.wa.customStatParams.pwd_id`、URL 路径三处取，页面版本不同位置也不同。
- 换链请求需携带**对应网盘的客户端 UA**；而取回的直链在下载时还需**页面 Referer 与 Cookie**，否则会被判为盗链。脚本会把这两项随直链一起保存并带入 Aria2 推送。
- 接口错误码有明确含义：`31001` 未登录、`23018` 超出游客可获取大小上限，均给出了对应提示。
- **重复条目的根源**是直链签名每次都变，所以入库按**文件名**合并，而不是按 URL。

## 配置 Aria2

在「设置」页填写：

| 字段 | 默认值 | 说明 |
|---|---|---|
| 服务器地址 | `http://localhost:6800` | 主机与端口写在一行。Aria2 常用 6800，Motrix 为 16800 |
| 密钥 | 空 | 对应 `rpc-secret`，未设置则留空 |
| 保存目录 | 空 | 留空使用 Aria2 默认下载目录 |
| 接口路径 | `/jsonrpc` | 一般无需改动 |

填完点「测试连接」，显示 `Aria2 1.36.0` 之类的版本号即表示通路正常。

> 若连接失败，请确认 Aria2 启动时带上了 `--enable-rpc --rpc-listen-all --rpc-allow-origin-all`。

## 扩展新网盘

在脚本的 `providers` 数组中追加一项即可：

```js
{
  id: "example",
  name: "示例网盘",
  match: /(^|\.)example\.com$/i,
  pages: { home: /^\/list/, share: /^\/(s|share)\// },   // 按 pathname 判页面类型
  mount: { home: [".toolbar"], share: [".share-bar"] },  // 各页型的工具栏挂载点
  header: { "Referer": "https://example.com/" },         // 直链所需请求头
  credential: true,                                      // 直链还需页面 Referer + Cookie 时置 true
  hint: "未识别到文件时给用户的提示语",
  collect() { /* 读框架状态，返回 [{ fid, name, size, dir }] */ }
}
```

**关于 `mount`**：填宿主页面上既有的容器选择器，脚本会把入口按钮注入其中。注意三点：

- 不要使用 `:has()` —— 旧内核会直接抛异常。
- 容器是异步渲染也没关系，脚本用 `MutationObserver` 等待其出现，不做轮询。
- 各页型填多个选择器时，命中第一个即注入；页面类型识别不出来时会合并全部候选。

**关于 `collect`**：返回 `[{ fid, name, size, dir }]`。`dir` 请用 `providerApi.isFolder(item)` 判定，它会自动适配各网盘的字段名；**不要**自己写死字段。

**关于 `resolve`**：想支持「勾选即换链」就实现 `async resolve(files, page)`，返回 `[{ url, name, size, headers }]`。请把该直链下载所需请求头放进 `headers`（用 `providerApi.downloadHeaders(provider)` 取），否则推送到 Aria2 后可能 403。

## 已知限制

- **文件夹换不出直链。** 网盘的 `file/download` 接口只接受文件 ID，文件夹需要先遍历内容。勾选里含文件夹时脚本会自动剔除并给出提示，请**进入文件夹后再勾选其中的文件**。
- **自动换链覆盖：夸克 / UC / 百度（分享页 + 网盘内页）。** 百度内页首次换链时会静默完成一次百度开放平台授权（需已登录百度账号），令牌缓存复用；其余网盘的勾选识别已实现，换链接口尚未接入，走「自动截获」。
- **读框架状态依赖框架内部字段。** 网盘升级框架或改字段名后可能读不到勾选，症状是列表始终为空、提示停留在「请勾选文件」；修复方式是更新对应 provider 的 `collect()`。
- **兜底捕获需要您先点一次下载。** 直链是网盘在您点击时才换回来的，脚本无法凭空得知，所以未勾选时「可用直链」是空的 —— 这是设计如此，不是故障。
- **宁可少收，不污染列表。** 兜底捕获只接受三条高置信渠道；某些 CDN 直链若既无特征、响应头也未声明 attachment，可能收不到。
- **注入点与页面识别依赖页面结构。** 网盘改版后可能出现「工具栏没出现按钮」的情况，此时请改用脚本管理器菜单入口；修复方式是更新对应 provider 的 `pages` / `mount`。
- **hook 可能被页面覆盖。** 极少数站点会在运行时重新赋值 `window.fetch` / `XMLHttpRequest`，那之后发起的请求不再被捕获，刷新页面重试即可。
- **百度 / 阿里等需登录态。** 直链通常带时效与鉴权，请在已登录的页面上操作。
- **IDM 推送**依赖 IDM 本地捕获端口（`127.0.0.1:1001`），仅较新版本支持。
- **Motrix 用户**把服务器地址填成 `http://localhost:16800` 即可（Motrix 内置 Aria2，默认端口 16800）。
- **注入的入口按钮**提供三种配色（跟随主题 / 白色 / 暗色，可在「偏好设置」切换）；若宿主工具栏有特殊排版（如绝对定位的子项），按钮可能无法完美对齐。
