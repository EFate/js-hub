# 网盘直链下载助手（netdisk-hub）

一个油猴脚本（Tampermonkey / Violentmonkey），在网盘页面勾选文件 → 一键换取直链 → 推送给 Aria2 / IDM / 浏览器高速下载，绕开客户端限速与浏览器单线程的慢。

> **范围**：只做 **百度网盘 / 夸克网盘 / UC 网盘** 三家。三家的勾选识别与直链换取都是**完整实现**，不存在「识别得到、拿不到直链」的中间态；不做半成品的网盘适配，也不为未支持的站点留占位配置。
>
> 夸克与 UC 是两家独立网盘（域名、换链接口、客户端 UA、分享页挂载点各不相同），只是**页面结构与换链协议一致**，所以共用一套采集与换链逻辑，各自带自己的接入信息。

支持：**百度网盘 · 夸克网盘 · UC 网盘**

## 快速用法

1. 安装脚本管理器（Tampermonkey / Violentmonkey / ScriptCat）
2. 新建脚本，粘贴 `netdisk-hub.user.js` 保存
3. 打开百度 / 夸克 / UC 网盘页面，**勾选**要下载的文件
4. 点工具栏上的「下载助手」→ 直链自动出现 → 选一个出口（Aria2 / 下载 / 复制）

> 文件夹换不出直链（网盘接口只收文件 ID），请进入文件夹后勾选其中的文件。

## 直链与账号的关系（必读）

**一句话：直链就是「你当前登录的账号」在网盘上点「下载」会得到的那条地址。** 脚本只做「提取与转交」，不改变账号权益。直链由网盘服务端按账号身份签发，下载速度也由服务端按账号判定。

### VIP 账号 vs 普通账号

| 账号 | 换链接口 | 下载速度 |
|---|---|---|
| **会员（SVIP / 超级会员）** | 与普通账号**同一条接口**，无专属换链通道 | **会员速度**（服务端按 Cookie 里的账号身份放行） |
| **普通账号** | 同上 | 普通速度（网盘对非会员限速） |
| **未登录（游客）** | 百度内页换链需要授权令牌，未登录不可换；夸克与 UC 可以换，但有**单文件大小上限**（超限提示 23018） | 最低档限速 |

> **脚本不能把普通账号变出会员速度** —— 那是服务端按 Cookie 判定的，任何直链工具都一样。脚本能保证的是：你账号**本来就有**的权益，通过 Aria2 / Motrix / IDM 多线程跑满，而不是被浏览器单线程浪费掉。

### 各网盘直链获取条件

| 网盘 | 换链接口 | 需要登录 | 直链校验 | 特殊说明 |
|---|---|---|---|---|
| **百度网盘（分享页）** | `tplconfig` 取签名 → `sharedownload` 换 dlink | ✅ 必须（Cookie 里的 bdstoken / jsToken） | 下载需 UA `pan.baidu.com`；**不带 Referer / Cookie** | 超过分享直接下载上限的文件需「保存到网盘」后在内页取 |
| **百度网盘（内页）** | OAuth 授权（30x 追踪 + 落地页捕获）→ `xpan/multimedia?method=filemetas&dlink=1` | ✅ 必须（开放平台 access_token） | 下载需 UA `pan.baidu.com`；**不带 Referer / Cookie**，且 dlink 必须随链带 `access_token`（否则判未授权 31326） | 首次使用自动完成授权（含自动确认表单），令牌缓存复用；令牌失效自动续期重试一次 |
| **夸克网盘** | `https://drive-pc.quark.cn/1/clouddrive/file/download?entry=ft&fr=pc&pr=ucpro` | 建议登录（未登录有单文件大小上限） | 下载需**夸克客户端 UA** + 页面 Referer + Cookie | 列表页与分享页**共用同一接口**；分享页自动带上分享 ID（`pwd_id`）与 `fids_token` / `stoken`；分批 15、节流 1s |
| **UC 网盘** | `https://pc-api.uc.cn/1/clouddrive/file/download?entry=ft&fr=pc&pr=UCBrowser` | 建议登录（未登录有单文件大小上限） | 下载需 **UC 客户端 UA** + 页面 Referer + Cookie | 同夸克一套协议，但**接口地址与客户端 UA 不同**（混用必然失败），脚本按域名自动分流 |

> **为什么百度不能带 Referer / Cookie？** 百度开放平台（xpan）直链校验的是「UA + `access_token`」这一对。一旦随行 `pan.baidu.com` 的 Referer 与登录 Cookie，服务器会把它当成**网页端会话**去校验，与开放平台令牌口径冲突，直接回 `31326 / user is not authorized`。夸克与 UC 相反，它们的直链**必须**带页面 Referer 与 Cookie。脚本按网盘分别处理（内部 `credential` 开关只对夸克 / UC 生效）。

### 直链的时效与使用要点

- **直链带签名，有时效**（几分钟到几小时不等）—— 换到后尽快推送，过期了重新获取
- **请求头必须随行**：直链不是裸地址，网盘会校验请求头，脚本已按网盘自动随链保存并带入 Aria2 推送
- **错误提示直达根因**：未登录 → 提示登录；游客超限 → 提示登录后获取；分享页过期 → 提示刷新页面；令牌失效 → 自动续期重试
- **换链走网盘自己的账号身份**：脚本用的是浏览器里的登录态（Cookie），所以在哪台机器、哪个账号登录，换出的就是那个账号的直链

## 功能一览

| 功能 | 说明 |
|---|---|
| **勾选即识别** | 读页面框架状态（React / Vue 内部实例的 props）拿勾选文件；读不到时面板会说明试过哪些通道，便于定位 |
| **自动换链** | 打开面板即自动换取直链，分批 + 节流避免触发风控 |
| **一键推送 Aria2** | JSON-RPC `aria2.addUri`，自动携带文件名、保存目录与业务请求头 |
| **批量操作** | 全部推送 / 复制全部直链 / 复制命令行 |

## 下载出口

每条直链固定三个出口：

| 出口 | 说明 |
|---|---|
| **推送 Aria2** | JSON-RPC `aria2.addUri`，自动携带业务请求头（UA / Referer / Cookie） |
| **下载** | 隐藏 iframe 触发浏览器原生下载 |
| **复制** | 复制原始直链，可粘到任意下载工具 |

可选出口（默认关闭，在「设置 → 偏好设置」打开）：

| 出口 | 说明 |
|---|---|
| **IDM** | 通过 IDM 本地捕获端口（`127.0.0.1:1001`）推送 |

## 入口

入口注入走**三级降级**，任何一级成功即可 —— 网盘改版换类名也不会失效：

| 级别 | 方式 | 说明 |
|---|---|---|
| ① | **精确选择器** | 三家各自配置的工具栏挂载点，用 `MutationObserver` 等它渲染出来 |
| ② | **文案匹配** | 精确选择器 3 秒内未命中时启动：在页面里找文案为「下载 / 保存到网盘 / 上传 / 转存」的**可见**按钮，取它所在的那一排按钮容器，入口落在该排**最右侧** —— 类名换了也不受影响，因为文案不变 |
| ③ | **脚本管理器菜单** | 点脚本管理器图标 → 菜单中的「打开下载助手」，不依赖页面结构 |

注入结果可在面板「关于」页查看（哪一级命中、宿主元素、试过的全部选择器），并可一键复制诊断信息。

**入口自愈**：网盘页面是单页应用，进入文件夹等操作会把工具栏整块重渲染、入口随之被拆走。脚本以低频心跳检查入口是否还连在页面上，被拆走就在新工具栏里重新挂载；工具栏迟迟未渲染时也会持续重试，不必刷新浏览器。

不注册任何全局快捷键，不生成悬浮球。

## 配置 Aria2

在「设置」页填写：

| 字段 | 默认值 | 说明 |
|---|---|---|
| 服务器地址 | `http://localhost:6800` | Motrix 用户填 `http://localhost:16800` |
| 密钥 | 空 | 对应 `rpc-secret` |
| 保存目录 | 空 | 留空使用 Aria2 默认下载目录 |
| 接口路径 | `/jsonrpc` | 一般无需改动 |

填完点「测试连接」，显示版本号即通路正常。

## 界面设计原则

**面板是操作面板，不是数据看板。**

- 下载页**只有一张「可用直链」主卡**，空列表只给一句语境化提示（去勾选文件 / 进入文件夹），**不展示统计**
- 批量按钮仅在有条目时出现，行内固定三出口（Aria2 · 下载 · 复制）
- 设置页**三张卡**：Aria2 服务器配置 + 百度网盘授权 + 偏好设置
- 偏好设置每项都是「名称 → 短说明 → 开关」，说明紧跟控件右侧，不放问号角标
- 结果在面板里看得见的不弹 toast；看不见的（推送队列、剪贴板）才弹
- 换链失败改为内联错误提示（比弹窗好：一直可见）

## 已知限制

- **文件夹换不出直链**：网盘接口只收文件 ID。勾选含文件夹时脚本自动剔除并给出提示，请**进入文件夹后再勾选其中的文件**
- **百度首次使用需授权**：自动完成（抓授权页表单并提交确认），缓存令牌复用
- **夸克与 UC 的直链时效较短**：建议换出后尽快推送
- **不拦截网络，也不包装原生 API**：脚本只做换链，不会去偷听页面请求（曾经这么做会把网盘自己的客户端安装包之类的资源误当成可下载文件）。若某个网盘以后换链失效，宁可让列表空着，也不会给你塞进来无关的东西
- **IDM 推送**依赖较新版本 IDM 的本地捕获端口
- **注入入口可能被宿主改版影响**：页面改版换类名时靠文案匹配兜底，进入文件夹等路由切换后入口会自动重新挂载；仍失效时面板「关于」页显示注入状态与试过的选择器，可用脚本管理器菜单兜底
- **其余网盘未纳入**：阿里 / 123 / 移动 / 天翼 / 迅雷等不在范围内 —— 与其留一堆半成品适配，不如把已支持的三家做扎实
