# 链接直跳助手（jump-hub）

一个油猴脚本（Tampermonkey / Violentmonkey / ScriptCat）：**点一次链接就直接到目标网站**，中间那些「安全提示 / 即将离开 / 确认跳转」的中转页统统跳过；网盘链接顺带把提取码也办了，统一在新标签页打开。


---

## 快速用法

1. 安装脚本管理器（Tampermonkey / Violentmonkey / ScriptCat）
2. 新建脚本，粘贴 `jump-hub.user.js` 保存
3. **正常点链接就行** —— 默认全开，不需要任何配置

打开面板的方式：脚本管理器图标 → 菜单「链接直跳 · 打开面板」。

面板只是用来看状态和改设置的地方，**日常使用完全不需要打开它**。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| **免中转直跳** | 中转链接自动换成真实地址，点击直接到目标站，不再「再点一次继续访问」 |
| **新标签打开** | 跳转统一在新标签页，原页面留着不打断 |
| **网盘自动带码** | 点网盘分享链接时自动拼上页面里的提取码，一次直达内容 |
| **分享页自动填码** | 落到网盘分享页后，提取码自动填进输入框并提交 |
| **中转页自动跳** | 万一已经落在中转页（别人分享的旧链接、历史记录），识别后自动走人 |
| **全站可用** | 不依赖站点名单：没适配过的网站，只要链接是「搬运外链」的写法照样识别 |

## 免中转的原理

四条出口层层兜底，任何一条生效就够了：

| 出口 | 做什么 | 为什么需要 |
|---|---|---|
| **改写链接** | 页面渲染出链接后，把地址就地换成真实目标 | 右键菜单、中键新标签、状态栏预览全都保留 |
| **点击兜底** | 点击那一刻再解析一次，直接导航 | 对付动态生成的链接、以及站点自己抢走点击的处理器 |
| **新标签打开** | 拦截后统一新标签打开 | 不打断你原来的位置 |
| **落地自跳** | 已经落在中转页时，评分识别后自动跳走 | 从旧链接、历史记录点进来时的兜底 |

### 不会弄坏的东西

- **同一个网站的链接不动**：`a.example.com` → `b.example.com` 视为站内导航
- **第三方登录不受影响**：`redirect_uri` / `return_url` 这类登录回跳参数原样放行，只处理本身就是跳转页的地址
- **已带提取码的链接不动**、网盘首页这类非分享路径不加参数
- **解不出、有歧义的一律不动**：宁可不管，不可管错

### 跳转形态覆盖

中转壳不止 `?url=` 一种写法。以下形态都能解，且解出来的必须是合法网址 + 跳转到别的网站，否则不动：

| 形态 | 例子 |
|---|---|
| 参数搬运 | `/go?url=target.com/x`（支持二次编码、base64、hex） |
| 路径内嵌编码 | `/go/aHR0cHM6Ly9…`、`/redirect/68747470…` |
| 链接文字即地址 | `<a href="/go?t=1">https://target.com/x</a>` → 按文字指向的地址走 |

### 中转页自动跳的评分

落地在中转页时，按信号评分决定要不要自动跳走（阈值 60 分，达线才跳）：

| 信号 | 加分 |
|---|---|
| 站点规则命中 | +70（直接达线） |
| 参数里确实带了别的网站的地址 | +25 |
| 路径像跳转页（`/go` `/jump` `/link` `/transfer` …） | +40 |
| 页面写着「即将离开 / 正在跳转 / 安全提示」 | +35 |
| 页面有倒计时 | +10 |
| 页面文本极短 | +5 |

同一个网站的目标不计分 —— 正常文章页不会因为路径里带 `/link` 就被跳走。

## 网盘提取码

识别 **21 家**网盘：百度网盘 · 夸克网盘 · UC 网盘 · 阿里云盘 · 腾讯微云 · 蓝奏云 · 123 云盘 · 4275 极速云 · 中国移动云盘 · 中国联通云盘 · 天翼云盘 · 迅雷云盘 · 115 网盘 · 360 云盘 · 奶牛快传 · 城通网盘 · 文叔叔 · 微盘 · 坚果云 · MEGA · FlowUs 息流。

不用选文字、不用复制粘贴 —— 脚本自己从页面里取码：

1. **就近优先**：从被点的链接往上一层找，链接旁边写的码就是它的。一个帖子里多条网盘链接各带各的码时，分得清谁是谁，不会把隔壁的码安到你头上
2. **整页唯一兜底**：全页只有一个码时直接采信
3. **歧义不猜**：页面上有多个不同的码、又分不清归属时，什么都不做 —— 照常打开分享页，你自己输。猜错比不填更糟

```
帖子：资源一 <a href="https://pan.baidu.com/s/1abc">百度网盘</a>  提取码：k9x2
     资源二 <a href="https://drive.uc.cn/s/9zz">UC 网盘</a>        访问码 7w3q
        ↓ 点第一个链接
https://pan.baidu.com/s/1abc?pwd=k9x2      ← 带的是 k9x2，不是隔壁的 7w3q
        ↓ 落在分享页
自动填进输入框 → 自动提交
```

**脚本加的参数，脚本自己读**，所以不依赖各家网盘认不认这个参数名 —— 认就直接进，不认就由脚本代填，两条路都通。

提取码标签的写法：中文（`提取码` / `访问码` / `密码` / `口令`…）不用分隔符也认；英文（`password` / `passwd` / `passcode`）必须带 `:` 或 `=` 才认，避免把英文正文当密码。

「解压码」是压缩包密码，不是网盘提取码，不会被拼给网盘链接；但它会计入「页面上有几个码」的判断 —— 页上出现了它，「整页只有一个码」的兜底就失效，别的链接不会被错拼。

## 入口与界面

- **零注入**：不往页面注入任何按钮，没有悬浮球，不注册任何全局快捷键
- **菜单入口**：管理器菜单随时能打开面板、重新扫描本页、重置统计
- **零提示**：成功的操作不提示 —— 免中转、带码、填码都不弹，人已经到地方了，结果自己会说话；提示只有首次安装那一次

## 设置

只留「用户真的会想关掉它」的开关——5 个开关，分 4 组：

| 组 | 开关 | 默认 | 什么场景下会想关它 |
|---|---|---|---|
| **主开关** | 总开关 | 开 | 临时不想用它 |
| **跳转行为** | 在新标签页打开 | 开 | 想原地跳转、不留原页面 |
| | 落地中转页自动跳走 | 开 | 想自己看一眼那个提示页 |
| | 压掉站点拦截 | 开 | 某个站的功能被压坏了 |
| **网盘** | 自动带提取码 | 开 | 抓错码（关掉后免中转不受影响） |
| **站点** | 本站不处理 | 关 | 某个站不能动 —— 一键切换，不用手打域名 |
| | 站点规则 · 49 条 | 全开 | 某条规则误伤（点标签停用单条） |

另有数据清理（统计与日志一键重置）。

从旧版升级不用管：旧设置**自动迁移**，迁移完旧键就丢掉，不留幽灵设置。

## 已知限制

- **取不到码就不带，也不猜**：码只在图片里、或要扫公众号才给时帮不上
- **短链解析不了**：`t.cn` / `bit.ly` 需要联网换取真实地址，脚本不发任何网络请求
- **同网站一律不跳**：`a.example.com` → `b.example.com` 视为站内（宁可少跳，不可跳错）
- **新标签会多出一个标签页**：想原地跳可在设置里关掉「在新标签页打开」
- **iframe 里也会运行**：为了覆盖 iframe 内的跳转链接；面板只在顶层窗口出现

## 隐私

脚本**不发任何网络请求**，不引入任何第三方依赖。数据只落在脚本管理器自己的存储里：

| 键 | 内容 |
|---|---|
| `jh.opt` | 开关设置 + 不处理名单 + 停用的规则 |
| `jh.stat` | 三个计数（只增不减，纯本地） |
| `jh.log` | 最近 20 条事件（时间 / 类型 / 去向地址，便于自查） |
| `jh.installed` | 首次安装提示标记 |

想清空：「设置 → 数据 → 重置统计与日志」，或在菜单里点「已免中转 N 次」。
