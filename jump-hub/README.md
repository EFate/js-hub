# 链接直跳助手（jump-hub）

一个油猴脚本（Tampermonkey / Violentmonkey / ScriptCat）：**点一次链接就直接到目标网站**，中间那些「安全提示 / 即将离开 / 确认跳转」的中转页统统跳过；网盘链接顺带把提取码也办了，统一在新标签页打开。

> 当前版本 **v1.3.1** · 变更记录见 `update.md` · 界面预览见 `preview.html`

> **一句话**：把「点链接 → 落到中转页 → 再点一次继续访问 → 手输提取码」这条四步路，压成「点一次」。
>
> **用法就是什么都不用做。** 没有选文字识别、没有弹窗确认、没有快捷键、没有成功提示，也不用先复制提取码 —— 点链接的时候脚本自己去页面上找。
>
> **无感是本脚本的第一验收标准**：成功的操作不提示（人已经到地方了，结果自己会说话），需要用户做的决定才出现在设置里。

---

## 快速用法

1. 安装脚本管理器（Tampermonkey / Violentmonkey / ScriptCat）
2. 新建脚本，粘贴 `jump-hub.user.js` 保存
3. **正常点链接就行** —— 默认全开，不需要任何配置

打开面板的方式（不悬浮、不占快捷键）：

| 场景 | 入口 |
|---|---|
| **本页处理过链接**、且找得到宿主页头工具栏 | 工具栏里的「**直跳**」按钮（与原生按钮并排） |
| 任意页面 | 脚本管理器图标 → 菜单里的「链接直跳 · 打开面板」 |

面板只是用来看状态和改设置的地方，**日常使用完全不需要打开它**。

> **入口不是常驻物。** 跳转本身是全自动的，按钮只是「脚本在这页确实干了活」的可见凭证，
> 所以它只在两件事同时成立时才出现：① 本页**地址被真的改写过**（中转壳剥掉 / 补上提取码）；② 找得到宿主页头工具栏。
>
> **网盘分享页永不注入** —— 用户都到分享页了，那里既没有中转需要剥、也没有提取码需要补，
> 脚本本就该收手，更不该往人家工具栏塞东西。一个页面一条链接都没动过，也同样不出声。
>
> 觉得多余？设置里把入口选成「**不显示**」，跳转功能完全不受影响。

## 它到底做了什么

四条出口，**层层兜底**，任何一条生效就够了：

| # | 出口 | 做什么 | 为什么需要它 |
|---|---|---|---|
| 1 | **改写 href** | 页面渲染出链接后，把 `href` 就地换成真实目标地址 | 最省事：保留原生右键菜单、中键新标签、状态栏预览 |
| 2 | **点击拦截** | 在 `click` 捕获阶段解析，直接导航；`preventDefault` + `stopPropagation` | 对付脚本动态生成的链接、以及站点自己抢走点击的处理器 |
| 3 | **新标签打开** | 拦截后统一在新标签页打开，原页面留着 | 不打断用户原来的位置；中键 / ctrl 点击语义一致 |
| 4 | **落地自跳** | 万一已经落在中转页，评分后 `location.replace` 走人 | 从别人分享的旧链接、历史记录点进来时的兜底 |

### 为什么不会「跳错」

判定层是独立的一层，**同主机、同注册域一律不动**：

- 百度搜索结果里指向 `baike.baidu.com` 的，不认为是外链 —— `www.baidu.com` 与 `baike.baidu.com` 注册域相同，拦下
- `pan.baidu.com` 页面上指向 `baidu.com` 的链接同理不动

### 全站可用，不靠站点名单（v1.3.0）

早期版本是「49 条站点规则 + 兜底」，**未适配站点上只要链接是异步渲染出来的就会漏**。
现在反过来：**通用识别是主干，站点规则只是加速**。

| 环节 | 做的事 | 为什么需要 |
|---|---|---|
| **通用解析** | 任何站点的任何链接，都按「参数名 + 多层解码 + 幂等回溯」解析真实目标 | 不依赖任何站点名单，没适配过的站点照样用 |
| **首屏扫描** | `DOMContentLoaded` 时把页面已有链接过一遍 | 静态页面一次搞定 |
| **增量扫描** | `MutationObserver` 收到新增节点 → 只扫这棵新子树 | Next.js / React 水合、无限滚动、懒加载的链接不会再漏 —— 这正是「同一页靠前的接管了、靠后的没接管」的根因 |
| **点击兜底** | 前三条都没赶上，点击那一刻再解析一次 | 最后一道，保证「点下去一定有反应」 |

站点规则命中时走确定性改写（更快更准），**没命中也一样能用**，两条路都收敛到同一个
`resolveLink()`，不会出现「有规则才准、没规则就废」的两套逻辑。

### 提取码不会张冠李戴（v1.3.0）

一个资源帖里并列三条网盘链接、只有中间那条带码时，早期版本会把这条的码
**就近算到隔壁两条头上**。现在取码有一条**归属判定**：

- 从链接往上爬时，**一旦容器里出现了别的网盘分享链接，立刻停止** ——
  说明已经越过「这一条自己的块」，进到了多条链接共用的段落 / 卡片列表，里面的码不专属于谁
- 只认网盘链接（不是所有外链），卡片里放个「官方教程」链接不影响判断

配套的三级取值不变：**就近**（≤4 层）→ **整页唯一才兜底** → **歧义就什么都不做**。
宁可不动，不可错动。

### 不会误伤的几类链接（重要）

把 `?redirect_uri=` 里的地址直接当外链改写，会把 OAuth 登录流程打断。所以参数表分两级：

| 级别 | 参数 | 采信条件 |
|---|---|---|
| **高置信** | `url` `target` `to` `goto` `jump` `link` `redirect` `dest` `u` `q` … | 出现即采信 —— 这些名字语义就是跳转，不会出现在授权链里 |
| **低置信** | `redirect_uri` `redirect_url` `return_url` `back_url` `urls` `?r=` `?src=` … | **只有页面本身就是跳转页**（路径像 `/go` `/link` `/jump` `/redirect` `/transfer`）时才采信 |

这条护栏有专门的回归测试盯着（端到端场景 3）。

## 覆盖站点

**49 条站点规则**（`SITES`），每条声明「怎么找到跳转链接 + 真实地址在哪 + 要不要改点击」：

| 类别 | 条数 | 站点 |
|---|---|---|
| 搜索引擎 | **7** | 百度搜索 · 百度贴吧（含安全检测页） · Bing 搜索 · Google 搜索 / 重定向页 · 360 搜索 · 搜狗搜索 |
| 社区 / 博客 | **24** | 知乎 · 掘金 · CSDN · GitCode · 码云 · 开源中国 · 博客园 · 简书 · 豆瓣 · 少数派 · InfoQ · 51CTO 博客 · 链滴 · LINUX DO · NodeSeek · NGA · 牛客网 · 酷安 · 力扣 · Steam 社区 · 哔哩哔哩游戏 WIKI · 花瓣网 · ACG 盒子 · 书签地球 |
| 内容 / 分享 / 文档 | **8** | 爱发电 · pixiv · 腾讯云开发者社区 · 腾讯兔小巢 · 语雀 · 金山文档 · 腾讯文档 · 石墨文档 |
| 社交 / 海外 | **10** | 微博（含短链接） · 微信（含开放社区） · QQ 邮箱 · PC 版 QQ · Twitter / X · Facebook · Instagram · YouTube |

> 表里的站点名与脚本里 `SITES[].name` 逐条对应，数字由 `test` 之外的核验脚本比对过，不是手写的。

**没适配的站点也能生效**：通用跳转参数表（`STRONG_PARAMS` / `WEAK_PARAMS`）覆盖了绝大多数「`?url=` 搬运外链」的写法。端到端场景 2 就是在完全没有规则的域名上验证这条路径的。

### 中转页自动跳的评分

站点规则没覆盖时，用评分制决定要不要自动跳走（阈值 60 分）：

| 信号 | 加分 |
|---|---|
| 站点规则显式命中 | +70（直接达线） |
| 参数里确实带了**跨站**地址 | +25 |
| 路径像跳转页（`/go` `/jump` `/link` `/transfer` …） | +40 |
| 页面写着「即将离开 / 正在跳转 / 安全提示 / 继续访问」 | +35 |
| 页面有倒计时 | +10 |
| 页面文本极短（< 260 字） | +5 |

同主机、同注册域的目标**不计分** —— 正常文章页不会因为路径里带 `/link` 就被跳走。

## 网盘：把提取码也一起办了

识别 **21 家**网盘（`PANS`）：百度网盘 · 夸克网盘 · UC 网盘 · 阿里云盘 · 腾讯微云 · 蓝奏云 · 123 云盘 · 4275 极速云 · 中国移动云盘 · 中国联通云盘 · 天翼云盘 · 迅雷云盘 · 115 网盘 · 360 云盘 · 奶牛快传 · 城通网盘 · 文叔叔 · 微盘 · 坚果云 · MEGA · FlowUs 息流。

两件事，**全自动**：

| 能力 | 说明 |
|---|---|
| **点链接自动带码** | 点网盘分享链接时，脚本自己去页面上找提取码，拼成 `?pwd=` 再跳 —— 一次点击直达内容，不用先复制提取码 |
| **分享页自动填码** | 落地后从 URL 的 `pwd` 参数读回码，填进输入框并提交（React / Vue 站点走 `_valueTracker` 那套，保证框架能收到 input 事件） |

### 提取码是从哪儿来的

不用你选文字、不用你粘贴 —— 脚本自己从页面里取：

1. **就近优先**：从被点的那个链接往上最多 4 层，取一个文本量合适的块来解析。一个帖子里有多个网盘链接、各带各的码时，靠这条分清谁是谁。
2. **整页唯一兜底**：全页只有一个码时直接采信（链接旁边没写、但帖子开头写了「本贴统一提取码」也能生效）。
3. **歧义不猜**：页面上有多个**不同**的码、而就近又找不到时，**什么都不做** —— 猜错比不填更糟。

```
帖子：资源一 <a href="https://pan.baidu.com/s/1abc">百度网盘</a>  提取码：k9x2
     资源二 <a href="https://drive.uc.cn/s/9zz">UC 网盘</a>        访问码 7w3q
        ↓ 点第一个链接
https://pan.baidu.com/s/1abc?pwd=k9x2      ← 带的是 k9x2，不是隔壁的 7w3q
        ↓ 落在分享页
脚本读回 pwd 参数 → 自动填进输入框 → 自动提交
```

**关键点：脚本加的参数，脚本自己读。** 所以不依赖各家网盘认不认 `pwd` 这个参数名 —— 认（百度 / 夸克 / UC）就直接进，不认就由脚本代填，两条路都通。

只加 query、**不动 hash** —— 部分网盘用 hash 做路由（如 `drive.uc.cn/s/xxx#/list`），改 hash 会把页面弄坏。

已经带码的链接不动它；网盘首页这类非分享路径也不会乱加参数。

### 提取码识别

中文标签（`提取码` / `提取碼` / `访问码` / `訪問碼` / `密码` / `密碼` / `解压码` / `提货码` / `口令`）允许不带分隔符 —— 「访问码 7w3q」就是这么写的。

拉丁标签（`password` / `passwd` / `pwd` / `passcode`）**必须带 `:` 或 `=`** 才认 —— 否则英文正文里的 "password below" 会被当成密码 `below`。

另有 URL 形态：`?pwd=abcd` · `#abcd`。

**不会**把天翼云盘的 `?code=<分享ID>` 误当成提取码（读码参数名单里有意排除了 `code`）。

## 入口与界面

遵守仓库统一的 UI 规范（`design-system/ghb-ui-spec.md`）：

- **不悬浮**：没有悬浮球、没有侧边吸附按钮
- **不占快捷键**：不注册任何全局快捷键（面板内的 `Esc` 关闭除外）
- **按需注入**：判据是「**本页有没有真被改写过的链接**」。够格了才把按钮挂进宿主已有的页头工具栏容器（`MutationObserver` 等容器出现），配方选 `position: static`，不脱离文档流。
  条件不足就**静默** —— 不硬凑注入点，更不会退化成悬浮件
- **网盘页收手**：网盘分享页是终点站，永不注入
- **菜单兜底**：无论注入成功与否，管理器菜单永远可用；入口也可以一键关掉

面板是 `jh-` 前缀的独立样式体系（变量 / 圆角 6·14px / 字号 13·12·11 / 层级 `2147483000+n`），懒挂载 —— 不打开就不往页面里塞任何节点。两张页：

| Tab | 内容 |
|---|---|
| **概览** | 「怎么用」说明、当前页命中的规则、三项累计数字（已免中转 / 已预解析链接 / 已带提取码）、最近 8 条事件、手动「重新扫描本页」 |
| **设置** | 5 个开关分 4 组（主开关 / 跳转行为 / 网盘 / 站点）、一键「本站不处理」、49 条规则逐条停用、入口按钮四档（含「不显示」）、数据清理 |

**提示只出现在两个地方**：首次安装那一次（否则没法确认脚本是否生效），以及你在面板里主动点按钮时的反馈。**脚本的所有自动行为一律零提示** —— 免中转、带提取码、自动填码都不弹，因为人已经到地方了，结果自己会说话。

界面截图见 `preview.html`（由 `node test/preview.js` 用真实脚本渲染生成，不会和脚本漂移）。

## 设置：只留「用户真的会想关掉它」的开关

一个开关存在的唯一理由是**用户会在某个场景下真想关掉它**。按这条尺子，v1.2.0 把原来的 10 个砍到 5 个：

| 组 | 开关 | 默认 | 什么场景下会想关它 |
|---|---|---|---|
| **主开关** | 总开关 | 开 | 临时不想用它 |
| **跳转行为** | 在新标签页打开 | 开 | 想原地跳转、不留原页面 |
| | 落地中转页自动跳走 | 开 | 想自己看一眼那个提示页 |
| | 压掉站点拦截 | 开 | 某个站的功能被压坏了（合并了原「点击时接管」+「接管 window.open」） |
| **网盘** | 自动带提取码 | 开 | 抓错码（合并了原「自动带码」+「自动填码」+「自动提交」） |
| **站点** | 本站不处理 | 关 | 某个站不能动 —— 一键切换，不用手打域名 |
| | 站点规则 · 49 条 | 全开 | 某条规则误伤（点标签停用单条） |

### 删掉的 5 个，以及为什么

| 删掉的 | 理由 |
|---|---|
| **改写页面跳转链接** | **实现细节**。「改写 href 还是拦截点击」是脚本内部的事，用户只要「点一下就到」这个结果 |
| **页面链接预解析** | **实现细节**。它的唯一用户可见收益是「中键 / 右键也免中转」，那本来就该默认有；脚本已经限流 + 上限 2000 条 |
| **网盘分享页自动填提取码** | 与「自动带码」是**同一件事的第二步**，不该分成两个开关 |
| **填码后自动提交** | 同上，第三步。而且「填了还要手动点提交」本身就和无感冲突 |
| **轻提示** | 成功提示删光后，它已无事可做 |

**合并的逻辑**：`压掉站点拦截` = 点击接管 + `window.open` 接管（都是「别让站点抢走这次点击」）；`自动带提取码` = 带码 + 填码 + 提交（都是「提取码这件事」）。**同一次用户意图，只给一个开关。**

升上来不用管：旧设置会**自动迁移**（`takeover`/`openHook` 任一关过 → `guard` 关；`panCode`/`panFill` 任一关过 → `panAuto` 关），迁移完旧键就丢掉，不留幽灵设置。

抓错提取码了？把「自动带提取码」关掉即可 —— 免中转部分不受影响。

## 测试

```bash
node --check jump-hub.user.js   # 语法校验
node test/smoke.js              # 冒烟（221 项）
node test/e2e.js                # 端到端（137 项，需 jsdom）
node test/preview.js            # 重新生成界面预览
```

jsdom 依赖装在仓库根的 `.tmp`：

```bash
mkdir -p ../.tmp && cd ../.tmp && npm i jsdom
```

排查用：`JH_ONLY=7 node test/e2e.js` 只跑第 7 个场景；`JH_SCRIPT=... node test/e2e.js` 换被测脚本。

**冒烟测什么**：多层解码（percent 双解 / 中文句号 / 零宽字符 / 协议相对 / base64 与 a1 前缀）、`resolveTarget` 的 13 种站点形态与幂等性、OAuth 参数护栏、`shouldJump` 判定、中转页评分、网盘识别与提取码往返、提取码标签的误报护栏（`key word` / `password below` 都不能被当成码）、规则表完整性（名字不重复 / host 是正则 / 同域族顺序正确）、样式与层级、无第三方依赖。

另有三组**守住设计意图**的静态断言（比功能测试更早拦住回退）：

- **第 10 组 · 设置收敛**：布尔开关必须恰好 5 个且就是那 5 个键／旧键必须彻底不存在／迁移映射逐条验证
- **第 11 组 · 无感**：`onClick` / `autoFill` / `tryAutoJump` 等**自动行为函数的函数体里不许出现 `toast(`**（按大括号配对抠出函数体再查，不是全文搜）；`toast()` 不再受设置项控制；新标签实现必须带 `noopener` 与 bypass 标记
- **第 12 · 13 组 · 全站泛化 + 入口按需**：增量扫描队列存在且只扫新增子树、`deepScan` 与 `scanRoot` 共用 `resolveLink`、提取码归属判定（公共容器即停）／`worthEntry` 三条判据、网盘页不注入、本页计数只算真实改写、延迟回调必须校验文档未失效

**端到端测什么**（把 `location` 换成可控桩，直接看「这次点击把浏览器带去了哪」）：

| 场景 | 断言重点 |
|---|---|
| 1 百度搜索 | 站外结果被改写、站内（baike）不动、点击新标签直达、站点自己的 click 处理器没跑到 |
| 2 未适配站点 | 点击捕获阶段兜底，导航里不出现中转页地址 |
| 3 授权链护栏 | `redirect_uri` / `return_url` 链接原样放行，零接管 |
| 4 通用中转页 | 评分达线的页面自动跳走 |
| 5 规则中转页 | `link.zhihu.com` 按规则 `replace` |
| 6 网盘分享页 | 自动填码 + 自动提交 + 计入统计 |
| 7 **网盘自动带码** | 两个链接各带自己的码（`k9x2` / `7w3q` 不串）、多码且不相邻时不猜、整页唯一码时连 `href` 一起改写、已带码的链接不动、网盘首页不加参数 |
| 7f **零提示** | 带码 + 免中转各触发一次、等足 1.4 秒，toast 容器里**必须一个都没有**，但统计照常计数 |
| 7g **新标签** | 默认开新标签且不占当前页；`newTab:false` 时回落当前页导航 |
| 7x **面板结构** | 只剩 概览 / 设置 两个 Tab；没有文本框、没有「识别选中 / 读剪贴板」按钮、菜单里也没有选文字命令 |
| 8 **设置架构** | 5 个开关 / 4 组卡片标题正确、实现细节类开关确实不再暴露、一键「本站不处理」落盘与移除、旧版 10 开关自动迁移 |
| 9 预解析 / 弹窗 / 豁免 | 普通 `a[href]` 被改写、`window.open` 接管、不处理名单与总开关整页跳过 |
| 10 入口形态 | 按需注入、网盘页不注入、没干活不出现、关掉后跳转照常、不重复注入、无悬浮件、无全局快捷键 |
| 11 真实页面回归 | touchgal.ink 资源帖真实 HTML：无码链接不被错加隔壁的码、已带码链接落标记、三条中转壳全剥、水合后才出现的链接被增量扫描接住 |

> 测试环境有个坑值得记一笔：脚本的延迟回调**按调用时读取全局 `document` / `location`**，所以每条场景装载新脚本前必须先 `window.close()` 掉上一条场景的窗口，否则上一条场景遗留的定时器 / `requestAnimationFrame` 会打进这一条场景的文档里（表现为「莫名其妙被别的站点规则改写了链接」）。`await` 一段固定时间盖不住所有动态回调，关窗口才是彻底隔离。
>
> 另一条：测试默认写入 `jh.installed = true`，把「首次安装提示」这条一次性 toast 排除掉 —— 否则「零提示」断言会因为这条提示而变得没有意义。

## 已知限制

- **取不到码就不带，也不猜**：页面上有多个不同的提取码、而链接旁边又没有时，脚本**什么都不做**（照常打开分享页，你自己输）。猜错比不填更糟
- **短链解析不了**：`t.cn` / `bit.ly` 这类需要联网换取真实地址，脚本不发任何网络请求，所以只能靠锚点文字里的地址（Twitter 那条规则就是这么做的）
- **提取码必须写在页面上**：脚本不读剪贴板、不联网查库。码只存在于图片里，或者要扫公众号才给，那它也帮不上
- **入口按钮不保证出现**：它只在「本页真有链接被改写」且「宿主有页头工具栏」时才出现，网盘分享页干脆不出现。这是有意的——跳转全自动，按钮只是锦上添花，管理器菜单才是稳定入口
- **不改写第三方登录链接**：见上文「不会误伤的几类链接」，这是有意的
- **同注册域一律不跳**：`a.example.com` → `b.example.com` 视为站内，不会接管（宁可少跳，不可跳错）
- **点击接管会屏蔽站点埋点**：这是「不要被拦截」的代价，介意可在设置里关掉「压掉站点拦截」
- **新标签会多出一个标签页**：这是「原页面留着」的代价，想原地跳就在设置里关掉「在新标签页打开」
- **`preview.html` 需要 jsdom 生成**：它只是预览，删掉不影响脚本
- **iframe 里也会运行**：为了覆盖 iframe 内的跳转链接，脚本在每个 frame 都会跑一遍引擎；但面板和管理器菜单只在顶层窗口出现

## 隐私

脚本**不发任何网络请求**，不引入任何第三方 `@require`。数据只落在脚本管理器自己的存储里：

| 键 | 内容 |
|---|---|
| `jh.opt` | 5 个开关 + 不处理名单 + 停用的规则名 |
| `jh.stat` | 三个计数（只增不减，纯本地） |
| `jh.log` | 最近 20 条事件（时间 / 类型 / 去向地址，便于自查） |
| `jh.installed` | 首次安装提示标记 |

想清空：「设置 → 数据 → 重置统计与日志」，或在菜单里点「已免中转 N 次」。
