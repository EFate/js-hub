# 更新日志

## v1.0.0（2026-11-06）

首发版本：把「M365 Copilot 限制解除」与「Copilot 自动选择 GPT Think deeper」两个独立脚本合并为一个可配置脚本。

- **解锁**：功能开关表（86 项）批量写入、Copilot 资格与许可置为已开通、内置应用入口放开、GPT-5.2/5.3/5.4 全档位开放、Claude 模型开放、身份地区改写为 US、导航栏 Chat/Cowork 补全（企业租户不改）。
- **模型**：自动选择模型（打开菜单 → 展开父项 → 选中子项 → 校验切换器文字）、深层推理子项优先、目标档位可自定义、失败按三档返回码重试（最多 3 次）。
- **通用**：切换结果 Toast 提示，可在设置中关闭。
- **面板**：3 组 Tab 设置面板，开关即时生效免刷新；状态区明示本页注入结果与自动选模型结论；提供「重新应用」与「重新选模型」两个手动动作；Esc/遮罩关闭；管理器菜单为唯一入口（零注入，无页面内按钮、无悬浮器件、无快捷键）。
- **合并时的两处行为修正**：
  - 子开关关闭改为「不写入该键族」，不再把宿主条目改写为关闭态——避免主动收回用户本就拥有的能力。
  - 自动选模型增加对话页判据，邮件/日历等没有模型切换器的页面直接跳过，不再空转重试。
- **健壮性**：`LAST_TEXT` 短路避免高频 DOM 复检反复 `JSON.parse` 大对象；路由钩子定义失败时降级为纯 DOM 复检；`requestAnimationFrame` 缺失时降级为定时器。
