# 更新日志

## v1.1.0（2026-11-06）

修复「自动切换模型不生效或偶尔才生效」，并新增大陆网络环境下的上传增强。

- **修复：中文界面下自动选模型必然失败**。旧版把目标档位写死成英文 `gpt-5.6 sol think deeper`，而中文界面的菜单项是 `GPT-5.6 Sol 深度思考`，三次重试全部落空。现改为按界面文字识别：抓取可见菜单行，用模型标识（`GPT-5.x` / `Claude`）与模式关键字（深度思考 / 快速响应，中英文均覆盖）定位档位，目标留空即自动选菜单里最新的可用模型。
- **修复：失败后菜单挂在页面上**。旧版点不中就放弃，模型菜单一直浮在界面上。现在任何失败路径都先按 `Esc` 收尾。
- **修复：说明文字被当成档位点掉**。菜单说明「决定要思考多长时间」含「思考」二字，宽松匹配会把它识别成档位行；现在模式关键字只匹配整行标签。
- **修复：重试必然抛错**。浏览器不允许对同一请求重复 `send()`（`readyState` 已非 `OPENED`，抛 `InvalidStateError`），旧的重试逻辑在此处直接失效；现在重试会按原方法、地址、请求头重建连接。
- **新增：附件上传自动重试**。包装上传类请求，遇断连 / 超时 / 408 / 429 / 5xx 按 300→600→1200ms 退避重试，最多 3 次；4xx 业务错误（体积过大、格式不支持、权限不足）不重试。
- **新增：上传失败自动再试**。页面出现「上传失败」类提示时自动点击其中的重试按钮，同一条提示只点一次。
- **新增：重试事件门控**。重试期间拦截原生进度与结果事件，只把最终结果交回页面——否则页面会把中途的 503 当成一次真实上传失败。
- **新增：设置面板网络组**：上传重试开关一个，状态区显示重试 / 自愈 / 最终失败次数。
- **健壮性**：模型目标文本改为允许留空（自动），旧版写死的默认值不再回填；执行层在配置尚未装载时按默认值运行，不再因 `OPT` 为空而静默失效。

## v1.0.0（2026-11-06）

首发版本：把「M365 Copilot 限制解除」与「Copilot 自动选择 GPT Think deeper」两个独立脚本合并为一个可配置脚本。

- **解锁**：功能开关表（86 项）批量写入、Copilot 资格与许可置为已开通、内置应用入口放开、GPT-5.2/5.3/5.4 全档位开放、Claude 模型开放、身份地区改写为 US、导航栏 Chat/Cowork 补全（企业租户不改）。
- **模型**：自动选择模型、深层推理子项优先、目标档位可自定义、失败按返回码重试。
- **通用**：切换结果 Toast 提示，可在设置中关闭。
- **面板**：分组 Tab 设置面板，开关即时生效免刷新；状态区明示本页注入结果与自动选模型结论；支持 Esc/遮罩关闭；管理器菜单为唯一入口（零注入，无页面内按钮、无悬浮器件、无快捷键）。
- **合并时的行为修正**：子开关关闭改为「不写入该键族」，不再把宿主条目改写为关闭态；自动选模型增加对话页判据，邮件/日历等页面直接跳过。
