# 更新日志

## v1.2.2（2026-11-06）

按 copilot.com 实时页面做能力清理与真实结构修复，版本号按补丁位 +1。

- **删除旧解锁组**：真实页面已不存在 `m365ChatFeatureSettings`、`userEntitlements`、`identity` 三个数据标签，也没有 `__staticRouterHydrationData`；因此移除资格、地区、Claude、GPT 全档位和导航补全整组代码与开关。设置从 12 项 / 4 组缩减为 7 项 / 3 组。
- **修复真实菜单行识别**：实测菜单 DOM 把标题和说明拼成「深度思考思考更长的时间以获得更好的回答」，旧版按整行等值匹配会漏掉深度档；现在按标题前缀识别，同时仍排除「决定要思考多长时间」。
- **修复切换器确认**：实测选择后切换器只显示「深度思考」，旧版要求模型标识导致误判失败；现在纯模式名也能确认成功。
- **扩展存储值识别**：除 `gpt-5.6` 和 JSON 模型字段外，也识别纯档位值 `deep` / `quick` / `auto`，避免宿主只保存枚举时无法自学习。
- **清理无效入口**：删除已无实际作用的「重新应用」按钮，面板只保留「重新选模型」。

### 实测

- 内置浏览器登录 copilot.com 聊天页：模型选择器初始为「自动」。
- 打开模型菜单确认真实项：自动、快速响应、深度思考、GPT-5.6 Sol 快速响应 / 深度思考。
- 实际选择「深度思考」后，切换器变为「深度思考」。
- 打开新标签页后恢复为「自动」，说明该偏好不是服务端跨标签保存；脚本保留存储预写与自学习路径解决这一点。
- 用不含个人信息的测试文本实际上传：附件从「即将完成上传」变为正式可发送附件，上传链路验证成功。
