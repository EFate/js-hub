# Copilot 增强助手

一个让 Microsoft 365 Copilot 更好用的浏览器用户脚本（Tampermonkey / Violentmonkey 等）：解除地区与模型限制、按界面语言自动选中目标模型档位，并为附件上传增加网络抖动重试。全部功能可在设置面板中独立开关。

## 功能一览

### 解锁

| 开关 | 作用 |
|---|---|
| 解锁功能与资格 | 把 Copilot 的功能开关、资格与许可置为已开通状态，放开内置应用入口 |
| 开放 GPT 全档位 | 放开 GPT-5.2 / 5.3 / 5.4 在 Premium、Starter、Chat、Reasoning 等各入口的可见性 |
| 开放 Claude 模型 | 放开 Claude 模型与 Claude 推理档位在网页版与企业版的可见性 |
| 地区识别为美国 | 把身份地区改写为 US 并声明位于可用区域，解除区域限制 |
| 补全导航入口 | 导航栏缺失 Chat 与 Cowork 时自动补上 |

### 模型

| 开关 | 作用 |
|---|---|
| 后台静默设定模型 | 新页面在应用读取前先把模型偏好写进页面存储，不打开菜单、不点击 |
| 必要时自动点选 | 后台预写未生效时才打开模型菜单点一次；成功后记住存储键，以后回到静默模式 |
| 优先深度思考 | 在同类模型里优先选「深度思考 / Think deeper」档位；关闭则优先「快速响应」 |
| 固定模型（可选） | 只在想锁定某个模型时填写，例如 `GPT-5.6` 或 `Claude`；留空则自动选菜单里最新的可用模型 |

### 网络

| 开关 | 作用 |
|---|---|
| 附件上传自动重试 | 上传接口因网络抖动失败（断连、超时、限流、服务端 5xx）时自动退避重试，最多 3 次 |
| 上传失败自动再试 | 页面出现「上传失败」类提示时，自动点击其中的重试按钮；同一条提示只点一次 |

### 通用

| 开关 | 作用 |
|---|---|
| 切换结果提示 | 模型切换成功或失败时在页面底部提示一次 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等脚本管理器）。
2. 新建脚本，粘贴本目录 `copilot-enhance.user.js` 的全部内容并保存。
3. 打开 Microsoft 365 Copilot、copilot.microsoft.com、Bing Chat 等页面即可生效。

## 使用

- 解锁与网络增强默认开箱即用，无需任何操作。
- 点击脚本管理器图标中的「打开设置面板」即可开关各项功能。
- 面板内切换开关**立即生效**，无需刷新页面；改动模型相关选项后会自动重新选择一次。
- 面板底部提供「重新应用」与「重新选模型」两个动作，用于页面状态异常时手动重试。
- 按 `Esc` 或点击遮罩可关闭面板。

## 行为说明

- **默认走静默模式**：脚本把目标模型写进页面自己的存储，刷新后应用直接按该偏好启动，全程不打开菜单、不点击。只有当预写因为结构改版没生效时，才退化为自动点选一次；那次点选同时会教会脚本「模型存在哪个键」，之后又回到静默。
- **模型档位按界面文字识别，不依赖固定语言**。「深度思考 / Think deeper」「快速响应 / Fast」等入口在中文、英文界面下都能正确选中；菜单里的说明文字（例如「决定要思考多长时间」）不会被误当成档位。
- **自动选择只在对话页面执行**：邮件、日历等页面没有模型切换器，脚本会跳过而不是反复重试。
- 切换流程为「打开模型菜单 → 识别目标档位 → 点击 → 校验切换器文字」，校验通过才算成功；失败时会主动关闭菜单并提示，不会把菜单留在页面上。
- **关闭某个子开关只是「不再写入」该类条目，不会把宿主已有能力改回关闭**。例如关闭「开放 Claude 模型」后，脚本不再修改 Claude 相关条目，你原本拥有的 Claude 选项不受影响。
- 上传重试只作用于上传接口：对话等其它请求不会被代理或重试。重试期间页面自身的失败回调不会被打断，只有最终结果才交给页面处理。
- 上传重试对「非临时性错误」不重试：文件过大、格式不支持、权限不足这类问题重试也不会成功，脚本会把失败如实交回页面。
- 页面状态区会说明本页的注入结果、自动选模型结论与上传重试次数。

## 限制

- 重试会重建上传连接（浏览器不允许对同一请求重复发送），因此适合网络抖动导致的中断。
- 文件本身超出服务端限额、或账号额度不足时，重试不会成功——这类属于服务端拒绝，不是网络问题。
- Copilot 的服务端会重新下发配置。若某项解锁在刷新后被还原，属服务端覆盖，可点面板内「重新应用」重试。
- 模型菜单的档位名称随微软发版变化。留空「固定模型」时脚本会自动选最新的可用模型；若想锁定特定档位，在菜单里看到什么就填什么（只需填模型部分，如 `GPT-5.6`）。
- 上传重试依赖页面通过常规请求发送上传数据；若宿主改用其它传输方式，重试不会介入。
- 自动切换依赖宿主页面的无障碍属性与菜单结构，宿主改版时可能失效，届时可用管理器菜单手动打开面板重试。

## 隐私

- 不主动发起任何网络请求，不收集任何数据；上传重试只复用页面自身的上传请求。
- 开关状态仅保存在本地脚本管理器的存储中。
