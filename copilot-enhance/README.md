# Copilot 增强助手

一个面向 Microsoft Copilot 网页版的浏览器用户脚本：在页面加载时优先把模型设为「深度思考」，必要时才点一次模型菜单；同时为附件上传增加网络抖动重试与失败自愈。零悬浮入口，设置面板从脚本管理器菜单打开。

## 功能一览

### 模型

| 开关 | 作用 |
|---|---|
| 后台静默设定模型 | 学到页面存储键后，在新页面读取前直接写入深度思考偏好，不打开菜单、不点击 |
| 必要时自动点选 | 尚未学到存储键时，打开模型菜单点一次；成功后记住存储键，以后优先静默写入 |
| 优先深度思考 | 优先选「深度思考 / Think deeper」；关闭则优先「快速响应」 |
| 固定模型（可选） | 想锁定某个模型时填写，例如 `GPT-5.6`；留空则自动选最新可用模型 |

### 网络

| 开关 | 作用 |
|---|---|
| 附件上传自动重试 | 上传接口断连、超时、429 或 5xx 时自动退避重试，最多 3 次 |
| 上传失败自动再试 | 页面出现「上传失败」提示时，自动点其中的重试按钮；同一提示只点一次 |

### 通用

| 开关 | 作用 |
|---|---|
| 切换结果提示 | 模型切换成功或失败时在页面底部提示一次 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等脚本管理器）。
2. 新建脚本，粘贴本目录 `copilot-enhance.user.js` 的全部内容并保存。
3. 打开 copilot.com 的聊天页即可生效。

## 使用

- 所有功能默认开启，无需在页面上找按钮。
- 点击脚本管理器图标中的「打开设置面板」可逐项开关。
- 面板内切换立即生效，无需刷新；「重新选模型」只用于页面状态异常时手动重试。
- 按 `Esc` 或点击遮罩关闭面板。

## 行为说明

- **模型菜单按真实页面文字识别**：菜单行可能是「深度思考思考更长的时间以获得更好的回答」这种标题与说明拼接形式，脚本按标题前缀识别，不会把「决定要思考多长时间」误当成档位。
- **切换器校验兼容纯模式名**：实际页面切换成功后切换器只显示「深度思考」，不再要求出现完整模型名。
- **静默优先**：脚本先尝试把偏好写入页面自己的存储；只有从未学到存储键时，才自动打开菜单点一次。那次点击会同时记录宿主的存储键，后续页面优先静默写入。
- **增强安装互相隔离**：存储监听、上传重试等安装失败不会阻断模型切换；即使浏览器冻结了相关原型，模型自动选择仍会执行。
- **只处理真实存在的功能**：旧版的资格、地区、Claude、GPT 全档位和导航补丁依赖 copilot.com 已不存在的宿主数据，已整体删除。
- **上传重试只作用于上传接口**：对话请求不会被代理或重试。重试会按原方法、地址和请求头重建连接，并拦住中间事件，只把最终结果交回页面。
- **非临时错误不重试**：文件过大、格式不支持、权限不足等 4xx 错误会如实交回页面。
- 面板状态区会显示模型设定结论与上传重试、自动再试、最终失败次数。

## 限制

- Copilot 的模型偏好不保证跨标签页由服务端保存；脚本通过本地存储预写来解决新页面回到「自动」的问题。
- 首次使用如果尚未学到宿主存储键，可能需要自动点选一次作为教学；之后优先静默写入。
- 上传重试依赖页面通过常规 XHR 发送上传数据；宿主改用其它传输方式时不会介入。
- Copilot 发版改动菜单结构或存储键时，模型自动设定可能暂时失效，可从面板手动「重新选模型」。

## 隐私

- 不主动发起任何网络请求，不收集任何数据；上传重试只复用页面自身的上传请求。
- 开关状态仅保存在本地脚本管理器的存储中。
