# Copilot 增强助手

一个让 Microsoft 365 Copilot 更好地工作的浏览器用户脚本（Tampermonkey / Violentmonkey 等）：解除地区与模型限制，并在页面载入后自动把模型切到你指定的档位。全部功能可在设置面板中独立开关。

## 功能一览

### 解锁

| 开关 | 作用 |
|---|---|
| 解锁功能与资格 | 把 Copilot 的功能开关、资格与许可置为已开通状态，放开内置应用入口 |
| 开放 GPT 全档位 | 放开 GPT-5.2 / 5.3 / 5.4 在 Premium、Starter、Chat、Reasoning 等各入口的可见性 |
| 开放 Claude 模型 | 放开 Claude 模型与 Claude 推理档位在网页版与企业版的可见性 |
| 地区识别为美国 | 把身份地区改写为 US 并声明位于可用区域，解除区域限制 |
| 补全导航入口 | 导航栏缺失 Chat 与 Cowork 时自动补上 |

### 模型

| 开关 | 作用 |
|---|---|
| 自动选择模型 | 页面载入后把模型切换器指向目标档位，已经是目标档位则不做任何操作 |
| 优先 Think deeper | 在目标模型族里优先选中带「Think deeper」的深层推理子项 |
| 目标档位关键字 | 模型菜单里的完整子项文字，留空则使用内置默认值 |

### 通用

| 开关 | 作用 |
|---|---|
| 切换结果提示 | 模型切换成功或失败时在页面底部提示一次 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等脚本管理器）。
2. 新建脚本，粘贴本目录 `copilot-enhance.user.js` 的全部内容并保存。
3. 打开 Microsoft 365 Copilot、copilot.microsoft.com、Bing Chat 等页面即可生效。

## 使用

- 解锁类功能默认开箱即用，无需任何操作。
- 点击脚本管理器图标中的「打开设置面板」即可开关各项功能。
- 面板内切换开关**立即生效**，无需刷新页面；改动目标档位后会自动重新选择一次。
- 面板底部提供「重新应用」与「重新选择模型」两个动作，用于页面状态异常时手动重试。
- 按 `Esc` 或点击遮罩可关闭面板。

## 行为说明

- **自动选择模型只在对话页面执行**：邮件、日历等页面没有模型切换器，脚本会跳过而不是反复重试。
- 切换流程为「打开模型菜单 → 展开目标模型族 → 选中子项 → 校验切换器文字」，校验通过才算成功；未通过时会提示你确认，而不是谎报成功。
- **关闭某个子开关只是「不再写入」该类条目，不会把宿主已有能力改回关闭**。例如关闭「开放 Claude 模型」后，脚本不再修改 Claude 相关条目，你原本拥有的 Claude 选项不受影响。
- 页面状态区会说明本页的注入结果与自动选模型的执行结论（已切换 / 本已是目标档位 / 未成功 / 本页跳过）。
- 脚本全程不发起网络请求，所有处理都在本地页面内完成。

## 限制

- Copilot 的服务端会重新下发配置。若某项解锁在刷新后被还原，属服务端覆盖，可点面板内「重新应用」重试。
- 模型菜单的档位名称随微软发版变化。目标档位在菜单里找不到时，自动切换会失败并提示；此时把「目标档位关键字」改成菜单中实际显示的文字即可。
- 自动切换依赖宿主页面的无障碍属性与菜单结构，宿主改版时可能失效，届时可用管理器菜单手动打开面板重试。

## 隐私

- 不发起任何网络请求，不收集任何数据。
- 开关状态仅保存在本地脚本管理器的存储中。
