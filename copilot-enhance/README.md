# Copilot 增强助手

一个面向 Microsoft Copilot 网页版的浏览器用户脚本：尽量在客户端解除地区可用性标记，并为附件上传增加网络抖动重试与失败自愈。自动切换模型功能已移除。

## 功能一览

### 地区

| 开关 | 作用 |
|---|---|
| 地区解锁（美国） | 在页面读取配置前挂钩 JSON 解析，把地区、资格、许可与授权状态改写为美国可用状态；同时处理可识别的 JSON 标签与页面存储 |

### 上传

| 开关 | 作用 |
|---|---|
| 附件上传自动重试 | 上传接口断连、超时、429 或 5xx 时自动退避重试，最多 3 次 |
| 上传失败自动再试 | 页面出现「上传失败」提示时，自动点其中的重试按钮；同一提示只点一次 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等脚本管理器）。
2. 新建脚本，粘贴本目录 `copilot-enhance.user.js` 的全部内容并保存。
3. 打开 copilot.com 的聊天页即可生效。

## 使用

- 地区解锁与上传增强默认开启，无需在页面上找按钮。
- 点击脚本管理器图标中的「打开设置面板」可逐项开关。
- 面板内切换立即生效，无需刷新页面。
- 按 `Esc` 或点击遮罩关闭面板。

## 行为说明

- **地区解锁只改地区相关字段**：会处理 `isCopilotEnabledRegion`、`isCodexEnabledRegion`、`isCopilotEligible`、`userCountryCode`、`isEURegion` 等已知字段，不修改账号、语言、主题等无关数据。
- **尽量早于宿主读取**：脚本在 `document-start` 安装 `JSON.parse` 钩子，覆盖页面水合数据和后续接口响应，同时处理可识别的 JSON 标签与本地存储。
- **自动切换模型已移除**：不会打开模型菜单、不会写模型偏好，也不会再尝试切换到「深度思考」。
- **上传重试只作用于上传接口**：对话请求不会被代理或重试。重试会按原方法、地址和请求头重建连接，并拦住中间事件，只把最终结果交回页面。
- **非临时错误不重试**：文件过大、格式不支持、权限不足等 4xx 错误会如实交回页面。

## 限制

- 地区解锁是**客户端配置改写**：如果微软服务端直接按 IP 拒绝请求，仅靠浏览器脚本无法改变网络出口，仍需配合可用地区的网络线路。
- 页面后续新增未识别的地区字段时，需要按实际响应补充映射。
- 上传重试依赖页面通过常规 XHR 发送上传数据；宿主改用其它传输方式时不会介入。

## 隐私

- 不主动发起任何网络请求，不收集任何数据；上传重试只复用页面自身的上传请求。
- 开关状态仅保存在本地脚本管理器的存储中。
