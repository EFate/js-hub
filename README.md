# js-hub

## github-accelerate.js

GitHub 镜像加速下载的油猴脚本（Tampermonkey / Violentmonkey）。自动在 GitHub 页面注入加速按钮，一键把下载换成镜像直链，**脚本本身不接管下载**——只挑镜像、给直链，下载一律交给浏览器原生通道，**Gopeed / IDM 等接管工具可正常工作**。作者：**EFate**

### 功能特性

- 自动识别 GitHub 页面上的下载场景（Release 资产 / Raw 文件 / 仓库归档 / Gist 等 9 类），一键注入加速按钮
- 纯直链交付：脚本不下载、不中转、不占内存，选中镜像后直接走浏览器原生下载，下载工具随时接管
- 双节点接口源 + 内置镜像测速兜底，一个接口挂了自动切换下一个
- 镜像健康度记忆：坏镜像失败自动剔除、恢复后自动回队，不再反复踩坑
- 下载前 HEAD 预检：确认镜像真的能给出文件再放行；失败自动换下一个镜像
- 下载时可选「节点选择弹窗」手动挑镜像，或关闭它进入全自动模式（自动选最快镜像、失败自动换下一个，进度用 Toast 显示）
- 左侧居中的可拖拽启动器（不占右下角），三页签面板：节点管理 / 注入开关 / 偏好设置

### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. Tampermonkey → 添加新脚本 → 粘贴 `github-accelerate.js` 全部内容 → 保存
3. 打开任意 GitHub 仓库 / Release 页面，左侧出现绿色启动器即生效

### 使用

- **下载文件**：页面上出现加速按钮（或点左侧启动器），点击即可下载；默认每次下载会弹出节点选择弹窗，选一个镜像或直接用推荐的
- **不想弹窗**：设置里关闭「下载时弹出节点选择」，之后全自动选最快镜像，失败会自动换下一个
- **管理节点**：面板「节点」页签可刷新、测速、勾选常用镜像（默认取最快的 10 个）
- **找不到了**：关闭启动器后，通过油猴菜单「打开加速面板」呼出；「显示侧边启动器」开关可随时控制显隐

### 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 下载时弹出节点选择 | 开 | 开 = 每次下载弹窗手选镜像；关 = 全自动选最快、失败自动换源 |
| 自动刷新节点 | 开 | 启动时检查节点缓存是否过期（缓存 1 小时） |
| 显示侧边启动器 | 开 | 关闭后可用油猴菜单「打开加速面板」呼出 |

### 常见问题

**点了下载没反应？**
脚本只负责生成镜像直链，点击后立刻交给浏览器原生下载通道，Gopeed / IDM 等工具会正常接管。若浏览器无反应（例如镜像不支持该文件），弹窗里有「复制链接」，粘贴进下载工具直接下即可。

**镜像为什么有时快有时慢？**
镜像列表来自公开聚合接口并按实测延迟排序，缓存 1 小时；下载失败会自动换下一个镜像，无需手动干预。
