# js-hub

## github-accelerate.js

GitHub 镜像加速下载的油猴脚本（v0.0.6 · 无感版）。（Tampermonkey / Violentmonkey）。自动在 GitHub 页面注入加速按钮，一键把下载换成镜像直链，**脚本本身不接管下载**——只挑镜像、给直链，下载一律交给浏览器原生通道，**Gopeed / IDM 等接管工具可正常工作**。作者：**EFate**

### 功能特性

- 自动识别 GitHub 页面上的下载场景（Release 资产 / Raw 文件 / 仓库归档 / Gist 等 9 类），一键注入加速按钮
- 纯直链交付：脚本不下载、不中转、不占内存，选中镜像后直接走浏览器原生下载，下载工具随时接管
- 双节点接口源 + 内置镜像测速兜底，一个接口挂了自动切换下一个
- 镜像健康度记忆：坏镜像失败自动剔除、恢复后自动回队，不再反复踩坑
- 镜像新鲜度缓存：预检过的镜像在 5 分钟内视为 fresh,直接 0ms 直发,跳过预检等待;失败自动换下一个
- 下载时可选「节点选择弹窗」手动挑镜像,或关闭它进入全自动模式(自动选最快镜像、失败自动换下一个)
- 右侧居中的可拖拽启动器（默认贴右，可拖到任意位置），三页签面板：节点管理 / 注入开关 / 偏好设置

### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. Tampermonkey → 添加新脚本 → 粘贴 `github-accelerate.js` 全部内容 → 保存
3. 打开任意 GitHub 仓库 / Release 页面，右侧出现绿色圆形启动器即生效

### 使用

- **下载文件**：页面上出现加速按钮（或点右侧启动器），点击即可下载；首次或长时间未用会有 ≤ 2.5s 预检；之后因新鲜度缓存命中 → 点完即发，无延迟
- **不想弹窗**：设置里关闭「下载时弹出节点选择」，之后全自动选最快镜像，失败会自动换下一个
- **管理节点**：面板「节点」页签可刷新、测速、勾选常用镜像（默认取最快的 10 个）
- **找不到了**：关闭启动器后，通过油猴菜单「打开加速面板」呼出；「显示侧边启动器」开关可随时控制显隐

### 设置项

| 设置 | 默认 | 说明 |
|------|------|------|
| 下载时弹出节点选择 | 开 | 开 = 每次下载弹窗手选镜像；关 = 全自动选最快、失败自动换源 |
| 自动刷新节点 | 开 | 启动时检查节点缓存是否过期（缓存 1 小时） |
| 显示侧边启动器 | 开 | 关闭后可用油猴菜单「打开加速面板」呼出 |
| 显示页面内镜像按钮 | 开 | 关闭后 GitHub 页面不出现注入加速按钮，只能用启动器手动打开弹窗 |

### 常见问题

**点了下载没反应？**
脚本只负责把镜像直链通过原生 a[download] 点击推到浏览器，下载事件由浏览器原生通道交给默认下载器或 Gopeed 浏览器扩展，脚本不接管下载。链路如下：

```
脚本（只管「发射」）
  │
  ▼
  <a download> 原生点击 ──→ 浏览器原生下载事件
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
        浏览器默认下载器                  Gopeed 浏览器扩展拦截
        （没装 Gopeed 时）                （chrome.downloads 监听）
```
若浏览器仍无反应（例如镜像不支持该文件），弹窗里有「复制链接」，粘贴进下载工具直接下即可。

**镜像为什么有时快有时慢？**
镜像列表来自公开聚合接口并按实测延迟排序，缓存 1 小时；下载失败会自动换下一个镜像，无需手动干预。
