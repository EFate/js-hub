# 知乎阅读增强助手

一个轻量的知乎浏览优化脚本：净化页面干扰、改善阅读体验、外链直连、支持夜间模式。全部功能在浏览器本地完成，不依赖任何第三方库，不发出任何网络请求。

## 功能

### 净化

- **隐藏登录弹窗** —— 未登录浏览时不再弹出登录框，页面保持可滚动。
- **隐藏侧边栏并居中内容** —— 隐藏各页面右侧边栏与推荐卡片，主栏内容居中显示（首页、问题页、搜索页、专栏页全覆盖）。专栏页会一并移除「目录」面板**及其外层占位列**（只藏面板不藏占位列时，正文仍会被挤向一侧），并按几何自适应把被写死的正文列**撑满可用宽度**、水平居中，左右不再各留一大片空白；正文最大宽度由下方的「文章页阅读宽度」决定 —— 宽屏取设定值，窄屏自动收成 88% 视口（下限 900 像素），不必为小屏单独调。打开页面瞬间还会先遮住尚未归位的页脚区域，避免首屏闪一下。
- **下滚自动隐藏顶栏** —— 向下滚动时收起顶部导航栏，向上滚动时恢复。

### 阅读

- **发布时间移至顶部** —— 回答的发布/编辑时间显示在卡片开头；文本只有「编辑于」时，自动从悬浮提示中补全具体发布日期。
- **图片原图显示** —— 自动加载未压缩的原始尺寸图片，懒加载占位图同步替换。
- **限制图片最大高度** —— 正文图片最高 500px，避免长图刷屏。
- **悬停时高亮当前卡片** —— 鼠标悬停的回答/搜索结果卡片显示淡蓝色边框。
- **引用角标高亮** —— 文内引用序号以蓝色加粗显示，便于定位参考资料。
- **GIF 自动播放** —— 点击页面任意位置后，静置的 GIF 图自动开始播放。
- **文章页阅读宽度** —— 用滑块调节专栏/回答正文的最大宽度：范围 900 ~ 2400 像素、步进 50 像素，默认 1500 像素。向右拖动更宽；拖动过程页面即时预览，松手才保存生效；窗口变窄时自动收缩，不必为小屏单独设置。该项依赖「隐藏侧边栏并居中内容」—— 该开关关闭时，本项在面板里自动置灰并给出提示。

### 链接

- **跳转链接直链化** —— 知乎外链不再经过中转确认页，直接打开目标网址；站内链接与已是直链的地址一律不动。

### 外观

- **夜间模式** —— 深色主题，切换即时生效，无需刷新页面。

## 用法

脚本安装后全自动生效，页面上不添加任何按钮或悬浮元素。所有功能通过脚本管理器菜单控制，共两项：

- **设置面板** —— 打开设置窗口，按「净化 / 阅读 / 链接 / 外观」四组分区管理全部开关与数值项（阅读宽度滑块），改动即时生效，按 Esc 或点击遮罩关闭。
- **夜间模式** —— 在菜单里一键切换深浅主题。

## 设置

每个开关都可以单独开关，改动立即生效、无需刷新；关闭某个功能后，对应效果立即消失（已改写的链接保留直链状态）。数值项（文章页阅读宽度）在拖动时即时预览、松手即保存，取值范围 900 ~ 2400 像素，越界的取值会被自动收进区间。默认开启：登录弹窗隐藏、侧边栏隐藏、时间置顶、原图显示、图片限高、悬停高亮、角标高亮、直链化；默认关闭：顶栏自动隐藏、GIF 自动播放、夜间模式。

## 限制

- 页面样式依赖知乎现有的 HTML 结构，站点大改版时个别开关可能暂时失效，更新脚本即可修复。
- 「隐藏登录弹窗」会同时屏蔽其他弹窗，适合未登录纯阅读场景；需要登录或使用弹窗功能时可临时关闭该开关。
- 「跳转链接直链化」只处理明确携带目标地址的中转链接，无法解析的中转地址保持原样打开。
- 部分内容（如回答全文折叠）由知乎服务端控制，脚本不强制展开。

## 隐私

- 不发出任何网络请求，不采集任何数据。
- 所有设置仅保存在浏览器本地。
