# 知乎阅读增强助手

一个轻量的知乎浏览优化脚本：净化页面干扰、改善阅读体验、外链直连、支持夜间模式。全部功能在浏览器本地完成，不依赖任何第三方库，不发出任何网络请求。

## 功能

### 净化

- **隐藏登录弹窗** —— 未登录浏览时不再弹出登录框，页面保持可滚动。
- **隐藏侧边栏并居中内容** —— 隐藏各页面右侧边栏与推荐卡片，主栏内容居中显示（覆盖首页、问题页、搜索页、专栏页）；专栏页会一并移除左侧「目录」面板，正文按内容宽度居中，不再偏左留白。打开页面瞬间还会先遮住尚未归位的页脚区域，避免首屏闪一下。
- **下滚自动隐藏顶栏** —— 向下滚动时收起顶部导航栏，向上滚动时恢复。

### 阅读

- **发布时间移至顶部** —— 回答的发布/编辑时间显示在卡片开头；文本只有「编辑于」时，自动从悬浮提示中补全具体发布日期。
- **图片原图显示** —— 自动加载未压缩的原始尺寸图片，懒加载占位图同步替换。
- **限制图片最大高度** —— 正文图片最高 500px，避免长图刷屏。
- **悬停时高亮当前卡片** —— 鼠标悬停的回答/搜索结果卡片显示淡蓝色边框。
- **引用角标高亮** —— 文内引用序号以蓝色加粗显示，便于定位参考资料。
- **GIF 自动播放** —— 点击页面任意位置后，静置的 GIF 图自动开始播放。

### 链接

- **跳转链接直链化** —— 知乎外链不再经过中转确认页，直接打开目标网址；站内链接与已是直链的地址一律不动。

### 外观

- **夜间模式** —— 深色主题，切换即时生效，无需刷新页面。

## 用法

脚本安装后全自动生效，页面上不添加任何按钮或悬浮元素。所有功能通过脚本管理器菜单控制，共两项：

- **设置面板** —— 打开设置窗口，按「净化 / 阅读 / 链接 / 外观」四组分区管理全部开关，改动即时生效，按 Esc 或点击遮罩关闭。
- **夜间模式** —— 在菜单里一键切换深浅主题。

## 设置

每个开关都可以单独开关，改动立即生效、无需刷新；关闭某个功能后，对应效果立即消失（已改写的链接保留直链状态）。默认开启：登录弹窗隐藏、侧边栏隐藏、时间置顶、原图显示、图片限高、悬停高亮、角标高亮、直链化；默认关闭：顶栏自动隐藏、GIF 自动播放、夜间模式。

## 限制

- 页面样式依赖知乎现有的 HTML 结构，站点大改版时个别开关可能暂时失效，更新脚本即可修复。
- 「隐藏登录弹窗」会同时屏蔽其他弹窗，适合未登录纯阅读场景；需要登录或使用弹窗功能时可临时关闭该开关。
- 「跳转链接直链化」只处理明确携带目标地址的中转链接，无法解析的中转地址保持原样打开。
- 部分内容（如回答全文折叠）由知乎服务端控制，脚本不强制展开。

## 隐私

- 不发出任何网络请求，不采集任何数据。
- 所有设置仅保存在浏览器本地。
