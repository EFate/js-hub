# 变更日志 · zhihu-enhance

格式：`版本 — 日期` 一行结论，下面列具体改动与验证证据。

## v1.0.0 — 2026-09-22

首发版本。整合四个旧知乎优化脚本的可用功能，按「功能必要性 + 最轻量普适实现」去重取舍，四组分类共 11 个开关。

### 功能取舍（ref 脚本 → 本脚本）

- **采纳**：隐藏登录弹窗（纯 CSS）；隐藏侧边栏并居中（两份重复实现合并为一份，取居中策略）；下滚自动隐藏顶栏；回答发布时间置顶 + 「编辑于」补全发布日期；图片原图显示（尺寸后缀白名单剥离，避免误伤 hash）；图片限高；悬停聚焦框；引用角标高亮；GIF 自动播放（默认关）；跳转链接直链化；夜间模式（属性门控方案，切换免刷新）。
- **砍掉**：题目栏注入按钮（举报/匿名/日志/快捷键）、信息流不感兴趣按钮与标签 —— 注入型实现重、随改版易碎，与零打扰原则冲突；隐藏图片/视频、通知气泡等长尾开关 —— 小众且增加设置噪音。

### 架构

- 七层：L1 配置（选项定义表 11 开关 / 4 组）→ L2 数据（设置对象单一数据源）→ L3 样式（按开关拼装，夜间主题常驻由属性门控）→ L4 核心逻辑（直链解析 / 原图归一 / 时间提取，纯函数 UMD 导出）→ L5 执行（DOM 动作全部带幂等标记）→ L6 UI（设置面板懒挂载，管理器菜单是唯一入口，零页面注入）→ L7 Watcher（唯一的监听者：MutationObserver 去抖 + scroll 节流 + 夜间主题守护）。
- 零依赖（不引 jQuery）、零网络请求、`@noframes`。

### 验证

- `node --check` 通过；测试 97/97（smoke：配置表 / buildCSS 逐开关 / 直链解析 12 例 / 原图归一 8 例 / 时间提取 7 例 / 护栏 9 项；e2e：直链化、时间置顶、原图替换、开关门控、sticky 清理五场景含幂等断言；文档核验：README 无版本号、无内部标识符、11 个开关说明全覆盖）。
- 测试揪出并修复三处真实缺陷：原图替换按长度截断误伤扩展名 → 改为整段匹配替换；直链编码兜底会把目标 URL 自身的查询串切掉 → 改为编码态按 `&` 截断后再解码；严格模式下 `arguments.callee` 抛错 → 改具名处理器。
